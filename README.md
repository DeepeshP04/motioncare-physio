# MotionCare

MotionCare is a responsive physiotherapy and rehabilitation clinic website built with React, Vite, TypeScript, React Router, vanilla CSS, and Lucide icons. It introduces the clinic, presents rehabilitation services, offers patient education articles, and provides contact and appointment-request pages.

## Pages

- `/` — Home
- `/about` — About MotionCare and its care approach
- `/services` — Physiotherapy and rehabilitation services
- `/education` — Patient education articles, with individual article pages
- `/contact` — Clinic contact information and message form
- `/appointment` — Appointment request form

## Run locally

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

Create a production build with `npm run build`, or preview it locally with `npm run preview`.

Clinic contact details and navigation are maintained in `src/siteConfig.ts`. The sample testimonials, team profiles, and educational content are editable demo content; update them with clinic-approved information before publishing.
